# Taxi 21 Cala Rajada

Web de taxicalaratjada.es (Astro + Tailwind). Las páginas están en `src/pages/[lang]/`, los textos en `src/i18n/ui.ts` y los datos del negocio en `src/consts.ts`. Se publica sola al hacer push a `main`.

`originales/` guarda logos y fotos a resolución completa; no se publican.
